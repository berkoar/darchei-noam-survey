# Darchei Noam Building Expansion Survey: live results

A public, read-only page with the latest results of the Congregation Darchei Noam Building Expansion Survey.

- `index.html` is the page. It loads the files in `data/` and calculates everything in the browser.
- `data/` holds a cleaned copy of the responses (names, emails, IP addresses and edit links removed), the comment themes, and `meta.json` with the last update time.
- A scheduled task refreshes `data/` around 8 AM and 8 PM Eastern until the survey closes on November 8, 2026.
